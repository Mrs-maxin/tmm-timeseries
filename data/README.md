# 复现输入

`case2bus/source_load.csv` 记录本次交流潮流教学算例的两条合成轨迹。每个 `trajectoryId` 恰好含两个时段。`period` 的 1、2 分别对应 18:00、18:15。`windMW`、`solarMW` 和 `loadMW` 为发电、光伏出力及负荷有功。`windMVAr`、`solarMVAr` 和 `loadMVAr` 为对应无功。发电和用电量分别记录，程序按发电减负荷求净注入。网络参数及低电压下限集中在算例入口。

后续录入风光荷数据时，记录时区、时间间隔、设备到节点的对应关系、无功来源及缺测处理方式。对训练和核对样本保留完整轨迹标识。
