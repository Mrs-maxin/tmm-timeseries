# 符号及单位

| 符号 | 含义 | 单位或维数 |
| --- | --- | --- |
| $t$ | 运行时段，教学算例取 1、2 | — |
| $P_t,Q_t$ | PQ 节点有功、无功净注入 | 源荷表分别为 MW、MVAr；潮流方程为 p.u. |
| $z$ | 上级母线至 PQ 节点的线路串联阻抗 | p.u. |
| $V_t=e_t+\mathrm j f_t$ | PQ 节点复电压 | p.u. |
| $x_t$ | 单时段电压直角坐标 | 两维 |
| $X$ | 两时段电压直角坐标 | 四维，按时段排列 |
| $V_{\min}$ | 指定电压幅值下限，教学算例取 0.95 | p.u. |
| $\pi_k,\mu_k,\Sigma_k,\nu_k$ | 分量权重、位置向量、尺度矩阵与自由度 | 首个和末个为无量纲 |
| $D$ | 电压幅值低于限值对应的二维圆盘 | 坐标为 p.u. |
| $p_{12}$ | 两个时段均低于电压下限的概率 | 无量纲 |
